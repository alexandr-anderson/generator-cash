# Agent Skills

Проектные скиллы агента хранятся здесь. Cursor автоматически находит каждый каталог с файлом `SKILL.md` и подключает его в Agent.

Пользовательские скиллы из `~/.cursor/skills/` на локальной машине **не** копируются в Cloud Agent. Всё, что должно работать в этом репозитории и в облачных агентах, кладите в `.cursor/skills/`.

## Как добавить скилл

1. Создайте каталог `.cursor/skills/<skill-name>/`.
2. Положите в него `SKILL.md` с YAML-frontmatter.
3. Поле `name` должно совпадать с именем папки: только строчные буквы, цифры и дефисы.

Минимальный пример:

```markdown
---
name: my-skill
description: Что делает скилл и когда его применять.
---

# My Skill

Пошаговые инструкции для агента.
```

Вызвать скилл вручную можно через `/skill-name` в чате Agent. Агент также может подхватить его сам, если `description` совпадает с задачей.

## Структура скилла

```text
.cursor/skills/
└── deploy-app/
    ├── SKILL.md          # обязательно: метаданные и инструкции
    ├── scripts/          # по желанию: исполняемые скрипты
    ├── references/       # по желанию: подробные справки
    └── assets/           # по желанию: шаблоны и статические файлы
```

Категории можно группировать вложенными папками. Идентификатор скилла — это папка, в которой лежит `SKILL.md`, а не родительская категория:

```text
.cursor/skills/
└── deploy/
    └── timeweb-deploy/
        └── SKILL.md      # name: timeweb-deploy
```

## Frontmatter

| Поле | Обязательно | Назначение |
| --- | --- | --- |
| `name` | да | Идентификатор. Должен совпадать с именем папки. |
| `description` | да | Что делает скилл и когда его использовать. По нему агент решает, релевантен ли скилл. |
| `paths` | нет | Glob-паттерны: скилл всплывает только при работе с подходящими файлами. |
| `disable-model-invocation` | нет | `true` — только ручной вызов `/skill-name`, без автоподхвата. |

Держите `SKILL.md` коротким. Длинные справки выносите в `references/` — агент читает их по мере необходимости.

## Где Cursor ищет скиллы

| Расположение | Область |
| --- | --- |
| `.cursor/skills/` | Этот репозиторий (каноничное место) |
| `.agents/skills/` | Альтернатива по стандарту Agent Skills |
| `~/.cursor/skills/` | Только локальная машина, не Cloud Agent |

В этом проекте новые скиллы добавляйте только в `.cursor/skills/`.
