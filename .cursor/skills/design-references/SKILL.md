Подбирай референсы **на русском**. Цель — живые URL и приёмы, не копирование чужого кода и картинок.

Перед поиском прочитай контракт из `design-direction`, если сессия уже была; иначе 2–3 уточнения или разумные дефолты (B2B beauty, warm, не чистый B2C «для себя дома»).

## Поиск

1. **Tavily** (search / extract / research), если MCP авторизован.
2. Иначе **WebSearch** и **WebFetch** — не останавливай работу.
3. Ищи премиум haircare / professional beauty / salon supply / editorial e-com (ориентиры вроде Oribe, Davines, Olaplex, Awwwards/Godly «beauty ecommerce»), плюс 1–2 русскоязычных, если качество визуала сопоставимо.
4. 6–10 **рабочих** URL (главная или shop). Проверяй, что ссылка открывается смыслом страницы, не только сниппетом.

GenerateImage — опциональный moodboard «атмосфера блока», не вместо URL.

## Формат выдачи

Для каждого сайта:

```markdown
### N. [Название](URL)
- **Зачем смотреть:** 1 предложение
- **Hero / типографика / motion / карточки:** что взять (приём), не копипаст
- **Риск для нас:** слишком B2C / тяжёлый 3D / нет каталога и т.п.
```

В конце попроси 👍 / 👎 / «частично» по номерам. Не внедряй дизайн, пока нет реакции хотя бы на половину списка.

## Moodboard-контракт

После оценок пользователя зафиксируй и не размывай без нового раунда:

```markdown
## Moodboard-контракт
**Must (3):** …
**Never (3):** …
**Референс-якоря:** URL, на которые равняемся
**Что не копируем:** логотипы, фото, точные сетки и тексты чужих брендов
```

Extract (Tavily/WebFetch) — только структура секций и описание motion. Чужие CSS/JS/ассеты не тащить в репозиторий.
