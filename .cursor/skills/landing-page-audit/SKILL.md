Проводи аудит **на русском языке**. Фокус: **B2B** — салоны и частные мастера (кератин, профессиональный уход). Цель — список конкретных правок с приоритетом, а не общие советы.

## Перед аудитом

1. Прочитай: `index.html`, `catalog.html`, `about.html`, `delivery.html`, `src/js/app.js`, `src/data/products.js`, `src/data/config.js`, `src/styles/main.css`.
2. Если возможно — открой сайт в браузере или проверь ключевые URL (стили, JS, картинки, 404).
3. Учитывай текущую модель: **Telegram-заказ**, цены «уточняется», официальный дистрибьютор FILO Professional в РФ.

## Чеклист (оцени каждый пункт: ✅ / ⚠️ / ❌)

### 1. Первый экран (hero)
- [ ] За 3 секунд понятно **кто продаёт**, **кому**, **что делать дальше**
- [ ] H1 говорит с **профессионалом**, не с конечным клиентом салона
- [ ] Есть один явный primary CTA (каталог / Telegram / уточнить цену)
- [ ] Визуал — продукт или процесс, не «абстрактная красота»
- [ ] Нет перегруза текстом и конкурирующих кнопок

### 2. Ценностное предложение
- [ ] Отличие от «просто косметики» сформулировано (Бразилия, нанотех, линейки под процедуры)
- [ ] Есть блок «для салона / для мастера» или это читается между строк
- [ ] Линейки (редуктор, лечение, home care, финиш) **связаны с задачами мастера**

### 3. Каталог и карточки
- [ ] Товар = название + **зачем в работе** + объём + CTA
- [ ] Фильтры по линейкам работают и понятны B2B
- [ ] «Уточняется» не выглядит как «нет в наличии» — рядом есть призыв написать в Telegram
- [ ] Картинки грузятся, alt-тексты осмысленные

### 4. Доверие и снятие риска
- [ ] «Официальный дистрибьютор» подкреплён фактами (год, география бренда — без выдумок)
- [ ] Контакты и Telegram видны до оформления заказа
- [ ] Доставка по РФ описана для **оптовых/повторных** заказов (хотя бы кратко)
- [ ] Нет «висящих» обещаний (оплата на сайте, если её нет)

### 5. Путь к заказу
- [ ] Корзина → форма → Telegram: **≤ 3–4 шага**, поля только нужные
- [ ] В Telegram уходит структурированный текст (салон, город, состав заказа)
- [ ] На мобильном путь не ломается (меню, корзина, кнопки)

### 6. Контент и UX-мелочи
- [ ] Единый тон: FILO Professional, не «FILO»
- [ ] Нет битых ссылок, пустых секций, налезающей вёрстки
- [ ] Секции чередуются: оффер → категории → хиты → о бренде → CTA

### 7. SEO-база (кратко, детали — скилл `seo-local`)
- [ ] Уникальные title/description на ключевых страницах
- [ ] Один H1 на страницу, логичная иерархия H2

## Формат отчёта

```markdown
# Аудит конверсии — [страница/сайт]

**Аудитория:** салоны + частные мастера (B2B)  
**Дата:** …

## Итог (1 абзац)
…

## Критично (сделать первым)
1. … — **эффект:** …
2. …

## Важно
…

## Можно позже
…

## Что уже хорошо
- …
```

Для каждого ❌ и ⚠️ указывай:
- **Где** (файл / блок / URL)
- **Проблема** (1 предложение)
- **Исправление** (конкретное действие или текст)
- **Приоритет:** P0 / P1 / P2

## После аудита

- Если пользователь просит «исправь» — начни с **P0**, затем P1. Не меняй всё сразу без согласования.
- Для текстов подключай скилл `conversion-copy`.
- Для мета-тегов и локального SEO — `seo-local`.
