Оптимизируй сайт под **поиск в России** с фокусом на **B2B**: салоны и частные мастера (кератин, профессиональная косметика FILO). Все рекомендации и тексты — **на русском**.

## Контекст проекта

- Домен: `filo-professional.ru` (если в проекте иное — уточни в `config` / у пользователя)
- Город дистрибьютора: **Санкт-Петербург**, доставка **по всей России**
- Страницы: `index.html`, `catalog.html`, `about.html`, `delivery.html`
- Статический сайт без CMS — правки в HTML и при необходимости в `src/data/`

## Целевые запросы (B2B, примеры — адаптируй под фактический ассортимент)

**Высокий приоритет:**
- filo professional купить оптом / для салона
- filo professional дистрибьютор россия / спб
- профессиональная косметика filo [линейка: кератин, бразильский уход, нано btx]
- filo cafe brasil / bio btx / nano btx купить мастеру

**Средний приоритет:**
- косметика для кератинового выпрямления профессиональная
- бразильская профессиональная косметика для волос опт
- filo professional каталог цены (без обещания цен на сайте — «уточняется» + Telegram)

**Geo-модификаторы:** «спб», «санкт-петербург», «россия», «доставка по россии» — в title/description/about/delivery, без спама.

## Что проверять и править

### 1. Meta-теги (каждая ключевая страница)

| Страница | title (~50–60 символов) | description (~140–160) |
|----------|---------------------------|-------------------------|
| Главная | бренд + B2B + geo или «официальный дистрибьютор» | кому, что, CTA (каталог / Telegram) |
| Каталог | «Каталог FILO Professional» + профессионалы | линейки, доставка по РФ |
| О нас | дистрибьютор, доверие | официальность, контакты |
| Доставка | доставка по России | сроки/условия как в контенте, без выдумок |

Правила:
- Уникальный title и description на каждой странице
- Primary keyword ближе к началu title
- Не дублировать один и тот же title на всех страницах

### 2. Заголовки и структура

- Один **H1** на страницу, согласован с intent (не «Главная», а смысл)
- H2 — секции (категории, хиты, доставка)
- Не пропускать уровни (H1 → H3)
- В каталоге — осмысленные подписи категорий (уже в JS/data)

### 3. Open Graph / соцсети (минимум)

На главной и каталоге при отсутствии — добавить:
- `og:title`, `og:description`, `og:url`, `og:type`, `og:locale` (`ru_RU`)
- `og:image` — hero или лого бренда (абсолютный URL)

### 4. Техническое (статический сайт)

- `lang="ru"` на `<html>`
- Canonical на ключевых страницах (self-canonical на `https://filo-professional.ru/...`)
- Alt у изображений товаров: «FILO Professional — [название товара]»
- Не блокировать индексацию без причины
- Проверить: все CSS/JS/картинки отдают 200

### 5. Локальное SEO (B2B дистрибьютор)

Рекомендуй пользователю **вне сайта** (не выдумывай, что уже сделано):
- Яндекс.Бизнес / Google Business — если есть офис/склад для связи
- Единое NAP (название, адрес, телефон) на сайте и в каталогах
- Telegram как канал связи — указать в `about` и footer consistently

На сайте:
- Блок контактов с городом (СПб) + «доставка по всей России»
- Страница «Доставка» с региональной формулировкой

### 6. Контент под long-tail (без переспама)

- Краткие SEO-абзацы на `about` / `delivery`: «официальный дистрибьютор FILO Professional в России…»
- В `products.js` — поле description можно расширить **1–2 предложениями** с профессиональным контекстом (кератин, восстановление), не keyword stuffing

## Формат выдачи

1. **Таблица текущее → рекомендуемое** для title/description/H1 по страницам
2. **Список правок в коде** (файл + фрагмент)
3. **5–10 целевых ключевых фраз** под B2B салоны/мастеров
4. **Чеклист после внедрения** (проверка в браузере, View Source)

## Ограничения

- Не обещай позиции в топе и не гарантируй трафик
- Не добавляй fake reviews / schema Review без реальных данных
- Schema `Organization` / `LocalBusiness` — только если пользователь дал точные legal/contact данные
- Цены в сниппетах не указывай, если на сайте «уточняется»
