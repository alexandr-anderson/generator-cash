Этот файл читает любой клиент Claude Code, открывший эту папку — независимо от того, где начат чат.
Здесь держим общий контекст, а не историю переписки. Обновляем по ходу работы (сам агент должен
дополнять/поправлять эти разделы, когда что-то меняется — не просить пользователя писать это руками).

## О проекте

postvmeste.ru — Next.js-монолит: сервис собирает на бренд-стиль пользователя визуалы (карусели/reels)
для соло-криэйторов. Пайплайн: анализ стиля → генерация → редактор → экспорт.

Подробности:
- **План работ (источник правды по приоритетам и статусу пунктов): [docs/work-plan.md](docs/work-plan.md)**
  — открывать в начале любой рабочей сессии, статус пунктов там актуальнее, чем то, что ниже.
- Архитектура и границы данных: [docs/architecture.md](docs/architecture.md)
- Карта системы: [docs/system-map.md](docs/system-map.md)
- Проверка гипотезы (concierge-тесты): [docs/concierge-playbook.md](docs/concierge-playbook.md)
- Брендбук: [docs/brand-guidelines.md](docs/brand-guidelines.md)

Стек: Next.js 16.3.3, React 19.2, Prisma 6.16 + MySQL, Tailwind 4, PM2. Деплой — bash-скрипты
в `scripts/` (`deploy-artifacts.sh`, `build-release.sh`, `bootstrap-server.sh`, `remote-restart.sh`)
на сервер (Timeweb). Алерты об инцидентах — в Telegram.
