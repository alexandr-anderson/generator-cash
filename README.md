# postvmeste.ru

**Визуалы для соцсетей в вашем стиле — за пару минут вместо вечера в редакторе.**

[postvmeste.ru](https://postvmeste.ru)

## Кому это

Экспертам, малому бизнесу и соло-креаторам, которые ведут соцсети сами. Тем, у кого есть что
сказать, но нет дизайнера, времени на Figma и желания каждый раз выдумывать оформление заново.

Знакомая история: мысль для поста есть, а на то, чтобы превратить её в аккуратную карусель,
уходит весь вечер — и на третьей неделе публикации просто прекращаются.

## Что сервис делает

Вы приносите тему и пару предложений по сути. Сервис возвращает готовый материал —
с текстом, картинкой и подписью:

- **Карусель** — серия из семи слайдов: заход, раскрытие мысли, призыв в конце.
- **Пост** — одиночная картинка с подписью и хештегами.
- **Обложка для Reels** — вертикальная обложка с хуком, чтобы ролик не терялся в ленте.

## Как это работает

1. **Рассказываете о себе** — ниша, аудитория, тон, фирменные цвета. Один раз при регистрации.
2. **Задаёте тему.** Можно добавить свой текст, а можно попросить сервис написать черновик за вас.
3. **Выбираете из вариантов.** Сервис предлагает несколько заходов к теме и несколько раскладок —
   вы берёте тот, который ближе.
4. **Правите и забираете.** В редакторе меняете текст, размер и цвета. На выходе — ZIP с
   картинками и готовой подписью, остаётся только опубликовать.

## Что делает результат «вашим», а не шаблонным

- **Единый стиль.** Цвета, шрифт и тон берутся из вашего профиля, а не из случайного шаблона.
- **Рубрики.** Постоянные рубрики — «Ошибки», «Кейсы», «Разборы» — запоминают своё оформление,
  поэтому лента выглядит как одна серия, а не как набор разных картинок.
- **Референсы.** Можно показать примеры, которые нравятся, и сервис подхватит их композицию.
- **Архив.** Всё созданное сохраняется — можно вернуться и переиспользовать.

## Статус

Сервис работает и им пользуются. На старте есть несколько бесплатных генераций, дальше —
недельный лимит по тарифу. Приём оплаты сейчас готовится.

Регистрация — по почте с подтверждением.
