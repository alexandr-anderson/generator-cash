## 1. Две шкуры

Это **не «светлая тема и её инверсия»**. Это два состояния одного языка, и у каждого свой характер:

- **«Рассвет»** — тёплый, воздушный, дневной. Фон: рассветное небо. Ощущение — «утро, когда есть силы что-то сделать».
- **«Ночь»** — глубокий, кинематографичный, собранный. Фон: тёмная атмосфера с фиолетовым источником света и бирюзовой искрой. Ощущение — «вечер, когда наконец никто не дёргает».

Обе обязательны. Ни один экран не считается готовым, пока не посмотрен в обеих.

### Правило, которое важнее эстетики

**Интерфейс не должен спорить с работами пользователя.** Продукт собирает контент в цветах бренда
*автора*: его карусель может быть какой угодно яркости. Наш chrome — рама, а не картина. Поэтому:

- в редакторе и превью интерфейс приглушается, а не соревнуется;
- клиентская палитра никогда не подмешивается в chrome студии — иначе человек перестаёт понимать,
  где его бренд, а где наш.

## 2. Цвет

Токены заданы **по ролям**, а не по цвету: `--panel` значит «поверхность карточки», и в каждой теме
разрешается в своё значение. Никогда не пишите цвет напрямую — берите токен.

| Роль | Токен | Рассвет | Ночь |
|---|---|---|---|
| Фон страницы | `--paper` | `#faf3ef` | `#07080f` |
| Поверхность карточки | `--panel` | `#ffffff` | `#12131f` |
| Основной текст | `--ink` | `#2a1f3d` | `#f4f5fb` |
| Второстепенный текст | `--muted` | `#6b5c85` | `#9498b3` |
| Границы | `--line` | `#e7dcd6` | `#262838` |
| Граница при наведении | `--line-strong` | `#d6c8bf` | `#3a3d52` |
| Акцент (декор) | `--accent` | `#e8734a` | `#8b7bff` |
| **Акцент (текст)** | `--accent-text` | `#b5471f` | `#8b7bff` |
| Второй акцент (декор) | `--spark` | `#a86ad8` | `#37e0c8` |
| **Второй акцент (текст)** | `--spark-text` | `#8a4fbe` | `#37e0c8` |
| Мягкая подложка | `--soft-accent` | `#fdece4` | `#1c1b33` |
| Выключенные поля | `--surface-muted` | `#f3ece8` | `#191b28` |
| Ошибка | `--danger` | `#dc2626` | `#f87171` |
| Подложка ошибки | `--danger-soft` | `#fef2f2` | `#2a1416` |
| Стекло | `--glass` | `rgba(255,255,255,.44)` | `rgba(255,255,255,.06)` |
| Кромка стекла | `--glass-line` | `rgba(255,255,255,.68)` | `rgba(255,255,255,.14)` |

### Парные токены — обязательны

У каждой заливки есть парный цвет надписи: `--on-ink` для фона `--ink`, `--on-accent` для `--accent`.
**Не пишите `color: #fff` на цветной заливке.** В тёмной теме `--ink` становится светлым, и белая
надпись исчезает на белом фоне. Эта ошибка уже жила в семи местах приложения, пока не завели пары.

### Контраст — измеренный, не предполагаемый

| Пара | Рассвет | Ночь |
|---|---|---|
| Текст на фоне | 14.05:1 | 18.37:1 |
| Подписи на фоне | 5.47:1 | 7.04:1 |
| `--accent-text` на фоне | 4.92:1 | 6.07:1 |
| Белый на `--accent-text` | 5.40:1 | — |
| Надпись на кнопке | 15.42:1 | 17.80:1 |

**Ловушка, ради которой заведены `--accent-text` и `--spark-text`:** яркий `#e8734a` на тёплой бумаге
даёт всего **2.74:1**, а белый на нём — **3.01:1**. Оба ниже AA. Яркие акценты годятся для рамок,
точек, градиентных пятен и заливок без текста; как только на цвете появляется надпись или сам цвет
становится текстом — берите текстовый вариант. В тёмной теме такой проблемы нет, там токены
совпадают.

## 3. Типографика

```css
--font-onest: Onest, system-ui, Arial, Helvetica, sans-serif;
```

**Onest, а не Outfit.** Outfit выглядит подходяще, но у него нет кириллицы: `subsets` — только
`latin` и `latin-ext`. Весь русский текст молча уехал бы в системный шрифт, и вы бы смотрели не на
тот дизайн, который выбрали. Onest — геометрический гротеск с кириллицей по рождению и девятью
начертаниями. Подключён через `next/font`, то есть отдаётся со своего домена, а не с CDN Google.

| Элемент | Размер | Начертание |
|---|---|---|
| Заголовок героя | `clamp(46px, 6.6vw, 96px)` | 200, ключевые слова 700 |
| Заголовок секции | `clamp(30px, 3.6vw, 50px)` | 200, ключевые слова 600 |
| Подзаголовок | 16–18px | 300 |
| Основной текст | 14px | 400 |
| Подписи | 11.5–13px | 300–600 |

Контраст веса — главный типографический приём: тонкое начертание рядом с жирным в одной строке
(«Сказать есть что. **Показать — некогда**»). Не смешивайте шрифтовые семейства ради выразительности;
акцент делается весом и цветом внутри Onest.

## 4. Стекло

Основной материал интерфейса. Работает **только поверх картинки** — на плоской заливке стекло
превращается в серый прямоугольник.

```css
.glass {
  background: var(--glass);
  border: 1px solid var(--glass-line);
  backdrop-filter: blur(20px) saturate(1.4);
}
```

Запасной путь обязателен: где `backdrop-filter` не поддержан, фон становится плотным, иначе текст
ляжет прямо на картинку.

```css
@supports not (backdrop-filter: blur(2px)) {
  .glass { background: color-mix(in srgb, var(--panel) 88%, transparent); }
}
```

`backdrop-filter` дорог на слабых телефонах — не вешайте стекло на длинные списки и на то, что
двигается при каждом кадре прокрутки.

## 5. Фоны

Фоны рисует **сам продукт** — тем же шлюзом `OPENAI_IMAGE_*` и той же моделью, что делает картинки
постов. Скрипт: [`scripts/backgrounds.mjs`](../scripts/backgrounds.mjs).

- По три фона на тему: они переключаются вместе с выбранным форматом.
- `.backgrounds-raw/` — исходники, в гит не идут. `public/backgrounds/*.webp` — то, что деплоится.
- Две ширины: полная и 960px для телефонов.

**Регенерация не воспроизводима.** Модель каждый раз рисует новое; `--force` даст другие картинки, и
прежние не вернуть. Источник правды — файлы в `public/backgrounds`, а не промпт.

### Промпт

Атмосфера, а не сюжет. Обязательные запреты — иначе модель кладёт мусор ровно туда, где заголовок:

```
Abstract atmospheric <рассвет | тёмная сцена>, <палитра>, layered haze, <настроение>,
subtle film grain.
Pure abstract atmosphere: absolutely no text, no letters, no words, no logos,
no people, no faces, no objects, no buildings.
Wide cinematic background plate with generous empty space in the left half
for overlaid typography.
```

### Вуаль

Поверх фона всегда лежит вуаль (`--veil`) — градиент, который держит контраст текста. На десктопе
она плотная слева, где колонка текста. На телефоне — плотная по всей высоте: фон фиксированный, и при
прокрутке любая секция может оказаться над самым светлым местом картинки.

## 6. Путь клиента

Фирменный приём: маршрут из пяти узлов, который **рисуется по мере прокрутки** и перерисовывается
при выборе формата. Третий узел всегда ключевой — там появляется картинка.

Шаги берутся из того, что продукт реально делает (заходы — из `SCENARIO_SPECS`, состав пакета — из
экспорта), а не из маркетингового текста. Если продукт изменится, путь надо чинить.

При `prefers-reduced-motion` линия отдаётся сразу нарисованной. На узких экранах линия скрывается:
она горизонтальная и в одну колонку не значит ничего.

## 7. Голос

| Черта | Мы такие | Мы не такие |
|---|---|---|
| Прямой | Короткие ясные формулировки | Корпоративный канцелярит |
| Дружелюбный | Рядом с автором | Панибратство и сленг ради сленга |
| Уверенный | Спокойная экспертиза | Обещания «взорвём охваты» |

Заголовки лендинга пишутся **в той же манере, в какой продукт пишет крючки**: короткая честная
провокация, узнавание вместо перечисления фич. Это не приём ради приёма — так страница
демонстрирует сама себя.

| Контекст | Тон | Пример |
|---|---|---|
| Интерфейс студии | Спокойный, конкретный | «Проверьте Brand DNA перед генерацией» |
| Заголовок лендинга | Смелый тезис | «Сказать есть что. Показать — некогда» |
| Ошибки | Без паники | «Файл не подошёл. Нужен PNG, JPEG или WEBP» |

### Запрещённые слова

| Избегаем | Почему |
|---|---|
| Шаблонный инфобизнес | Против голоса студии |
| Гарантия результата | Нельзя обещать без фактов |
| Revolutionary, seamless | Пустые англицизмы и шаблонный AI-текст |

Отдельно: **не обещаем того, чего продукт не делает.** Оплата не подключена — так и пишем. Ролики не
снимаем — говорим об этом на лендинге, а не после регистрации.

## 8. Чего не делаем

| Избегаем | Почему |
|---|---|
| Центрированный герой с тремя одинаковыми карточками | Это дефолт SaaS-шаблона, а не наш язык |
| Стекло на плоской заливке | Без картинки за ним это просто серый блок |
| Яркий акцент под мелким текстом | 2.74:1 в светлой теме — нечитаемо, есть `--accent-text` |
| `color: #fff` на цветной заливке | В тёмной теме превращается в белое на белом |
| Клиентская палитра в chrome студии | Путает, где бренд автора, а где наш |
| Больше 8–12 слов на обложке | Не читается в ленте и в Reels |
| Анимация без `prefers-reduced-motion` | Часть людей от неё физически укачивает |

## Что изменилось с версии 1.0

Версия 1.0 описывала другой продукт: коралл `#FF5C35` как единственный акцент, Arial, только светлая
тема, и прямой запрет на фиолетовые градиенты («LLM-default slop»).

Направление сменилось осознанно, вместе с пользователем, после разбора референсов: выбран язык из
двух шкур со стеклом и генеративными фонами, где фиолетовый — рабочий цвет тёмной темы, а не ошибка.
**Старые запреты сняты не по недосмотру.** Если следующая сессия увидит фиолетовый градиент — это
так и задумано; чинить обратно к кораллу не нужно.

Сохранено из 1.0 без изменений: голос бренда, запрет на клиентскую палитру в chrome студии, предел
плотности текста на обложке.
